# @memroos/memory-contracts

The dependency-free wire contract for MemroOS's OpenAI memory tools. It exposes
the stable scope, tool, error, limit, and JSON-schema contract values without
importing application, policy, storage, or memory-engine code.

Development commands:

```bash
npm run build
npm run typecheck
npm test
npm run check:build
```
