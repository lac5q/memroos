# MemroOS Open Core

This directory is a narrow, standalone demand-test candidate containing deterministic memory primitives and wire contracts. It is licensed under Apache-2.0.

It does not include the MemroOS application, hosted operations, customer data, deployment state, credentials, logs, or private integrations.

## Build and test

```sh
npm install
npm test
```
